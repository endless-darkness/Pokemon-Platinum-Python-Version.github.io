# Game downloads

Place the distributable game files in this folder before publishing the website:

- `PokemonPythonPlatinum.exe` — Windows download
- `PokemonPythonPlatinum.elf` — Linux download

The buttons in `../index.html` link directly to these files. Filenames are case-sensitive on the host. If you use different filenames, update the corresponding links in `index.html`.
